# AI 数据处理与隐私补充声明

最近修订日期：2026 年 8 月 12 日
生效日期：2026 年 8 月 12 日

## 导言

本声明是 SEOC Studio[隐私政策](privacy-policy)的补充，专门说明您在使用研智助手时，您的输入与输出数据如何流转、存储与处理。如本声明与隐私政策存在不一致，在研智助手范围内以本声明为准。

## 第一条 数据流转路径

1.1 当您在研智助手发起对话或通过 API 调用接口时，您的输入内容（包括对话历史与系统提示）将通过本公司部署的 Supabase Edge Function 转发至所选模型对应的第三方厂商接口，由厂商完成推理并返回输出。

1.2 本公司的 Edge Function 在转发前会校验您的登录状态或 API 密钥、查询模型配置与研点余额、估算并监测 token 消耗，但不修改您的对话语义内容。

1.3 输出内容由厂商接口返回至 Edge Function，再以流式方式实时推送至您的客户端。在此过程中，本公司不主动永久存储对话明文，但会记录调用元数据用于计费与异常排查。

## 第二条 数据留存

2.1 本公司留存以下元数据，留存期限不超过六个月：用户标识、调用时间、所选模型、输入与输出 token 数量、消耗研点、是否使用免费额度、是否中断。这些数据不包含对话明文。

2.2 对话明文的留存遵循下列规则：流式输出过程中的中间文本仅在内存中短暂存在，输出结束后不主动落库；您在客户端看到的对话历史存储在您本地浏览器，清空浏览器数据或注销账户后即消失。

2.3 出于安全审计与合规要求，在接到有效法律文书或发现严重违规时，本公司可在六个月留存期内调取相关元数据进行核查，但不会调取对话明文（因其未被持久化存储）。

## 第三条 第三方厂商的数据处理

3.1 您的输入内容在调用时会被传输至第三方模型厂商。各厂商对输入数据的留存、再训练与隐私政策各不相同，详见[第三方 AI 模型使用说明](ai-third-party-models)。

3.2 本公司已在厂商选择上优先考虑提供数据不留存或不用于再训练承诺的服务，但无法替厂商作出保证。如您处理的资料涉及商业秘密、个人敏感信息或合规要求，请在输入前评估风险，必要时对敏感内容脱敏。

3.3 您不应在研智助手中输入违反法律法规或他人隐私的信息，不应输入您受保密义务约束不得外发的资料。因您输入不当内容引发的后果由您承担。

## 第四条 API 调用的特殊性

4.1 通过 API 密钥发起的调用，其输入与输出同样会传输至第三方厂商，且不享受免费额度。API 调用的计费与日志规则与网页端一致，详见[API 开放平台服务条款](ai-api-terms)。

4.2 您应妥善保管 API 密钥，密钥泄露导致他人调用产生的研点消耗由您承担。发现密钥泄露请立即在 API 密钥管理页撤销并重新创建。

## 第五条 您的权利

5.1 您有权查阅本人的调用元数据与交易流水（研点管理页提供），有权申请注销账户。账户注销后，与您关联的留存元数据将在六个月保留期满后删除。

5.2 如您认为本公司留存的数据存在错误或需要更正，请通过 jiangtengqiao@qq.com 提出。

## 第六条 未成年人

研智助手谢绝未成年人独立使用。监护人陪同未成年人使用时，应避免输入未成年人的个人敏感信息，并对使用过程承担指导责任，详见[未成年人保护声明](minor-protection)。
