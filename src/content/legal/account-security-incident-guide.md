# 附加追则条款四：账号安全事件应急指引

**最近修订日期：2026年8月14日  生效日期：2026年8月14日**

## 声明与指引性质

本《账号安全事件应急指引》（以下简称“本指引”）是《账号安全与身份验证政策》的附属文件，为账号安全事件（如账号被盗、密码泄露、异常登录等）提供具体的应急处置操作步骤。本指引不具有独立法律效力，仅作为操作指南，与《账号安全与身份验证政策》配套使用。

**跳转指引**：本指引从属于《账号安全与身份验证政策》。查看该政策全文请点击：《账号安全与身份验证政策》。

## 第一章 总则

### 1.1 目的

本指引旨在帮助用户和平台在账号安全事件发生时，能够快速、有序地采取行动，最大限度减少损失。

### 1.2 适用场景

本指引适用于以下账号安全事件：

1. 账号被他人登录；

2. 密码被他人修改；

3. 注册邮箱可能已被盗；

4. 收到非本人操作的验证码邮件；

5. 发现账号存在异常操作（如研点被异常消耗、讨论区发布了非本人内容）；

6. 其他账号安全风险。

## 第二章 用户应对步骤

### 2.1 发现异常后的即时行动

用户发现账号异常后，应立即按以下顺序采取行动：

1. **尝试登录**：如仍能登录，立即修改密码。

2. **无法登录**：通过“忘记密码”尝试重置密码。如重置邮件未收到或邮箱可能被盗，直接联系平台。

3. **联系平台**：通过官方邮箱 jiangtengqiao@qq.com 发送“紧急冻结”请求，主题注明“账号紧急冻结：您的昵称”。

4. **检查邮箱**：登录注册邮箱，检查是否有非本人操作的邮件，如密码重置邮件、验证码邮件等。

5. **修改邮箱密码**：如邮箱可能被盗，立即修改邮箱密码并开启双因素认证。

6. **解除第三方绑定**：如绑定了QQ或微信，先解除绑定（如可能）。

7. **收集证据**：保存异常登录时间、异常操作截图、可疑邮件等证据，后续提交平台。

### 2.2 平台响应后的配合

平台冻结账号后，用户应配合平台进行身份验证和恢复：

1. 按平台要求提供身份证明（如身份证影印件，可加水印）；

2. 说明账号异常情况的时间线和已知信息；

3. 确认恢复后的安全设置（修改密码、更新邮箱等）。

### 2.3 恢复后的安全加固

账号恢复后，用户应：

1. 设置新的高强度密码；

2. 检查并删除陌生的第三方绑定；

3. 检查账号内的数据（如研点余额、已购内容、讨论区发帖）是否有异常变动；

4. 在设备上查杀病毒/木马；

5. 考虑开启邮箱双因素认证。

## 第三章 平台应对步骤

### 3.1 接收报告与冻结

平台收到账号安全事件报告后：

1. **立即冻结**：在 **24小时** 内冻结相关账号，阻止进一步非法操作。

2. **记录信息**：记录报告时间、报告人联系方式、事件描述。

3. **初步评估**：判断事件类型（被盗、密码泄露、异常登录等）。

### 3.2 调查与验证

1. **日志分析**：调取账号登录日志、操作日志、API调用记录等，确认异常时间段和行为。

2. **身份验证**：通过邮箱验证码、注册信息或身份证明核实报告者身份。

3. **影响评估**：评估异常期间账号数据是否有损失（研点消耗、内容篡改、数据导出等）。

### 3.3 处置与恢复

1. **恢复账号**：身份核验通过后，协助用户重置密码，解除异常会话。

2. **数据恢复**：如研点被异常消耗、内容被删除，根据平台记录尽可能恢复。

3. **安全加固**：建议用户修改密码、检查邮箱、解绑异常第三方。

4. **事件记录**：形成事件处理记录，留档备查。

### 3.4 用户告知

平台在处置过程中和处置完成后，通过邮件或站内信告知用户：

1. 冻结和恢复时间；

2. 调查结果摘要；

3. 已采取的补救措施；

4. 对用户的后续建议。

## 第四章 特殊场景的处理

### 4.1 邮箱被盗且无法找回

如用户注册邮箱已被盗且无法找回，平台可能要求用户提供身份证明文件以证明账号归属，验证通过后协助更换绑定邮箱。更换邮箱后，原邮箱立即失效。

### 4.2 第三方账号被盗

用户绑定的QQ/微信被盗，攻击者可能通过第三方授权登录平台。平台在收到用户通知后：

1. 立即解除第三方绑定；

2. 重置用户平台密码；

3. 建议用户在第三方平台申诉找回。

### 4.3 账号被用于违法活动

如账号被盗期间被用于发布违法内容或实施攻击，平台在恢复账号的同时：

1. 删除违法内容；

2. 向用户说明情况；

3. 如涉及刑事犯罪，依法向公安机关报告；

4. 用户可向平台申请出具账号被盗证明，以备向有关部门自证清白。
