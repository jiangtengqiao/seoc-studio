本政策与《用户服务协议》《隐私政策》《用户账号注销与数据删除政策》《可接受使用政策》《数据安全与数据泄露应急响应政策》等文本共同构成完整约定。本政策中关于账号安全的技术措施描述，反映的是本政策生效日期的实际状况，我们可能根据安全形势变化和技术发展不断完善。

**特别提示**：账号安全需要您与我们共同努力。无论我们采取多么严格的安全措施，一个弱密码、一个已泄露的邮箱、一次在公共设备上的疏忽操作，都可能导致您的账号被他人获取。请认真阅读本政策第三章“您的账号安全责任”，并切实履行。

## 第一章 总则

### 1.1 制定目的

本政策的制定旨在实现以下目的：

1. **明确平台安全措施**：向用户清晰说明平台为保障账号安全所采取的技术手段和管理制度，增强用户对平台的信任。

2. **明确用户安全责任**：告知用户在账号安全保护中应承担的义务和可采取的防护措施，帮助用户增强安全意识。

3. **规范身份验证流程**：说明平台在哪些场景下需要验证用户身份、通过什么方式验证、验证的流程和标准。

4. **建立风险处置机制**：建立账号安全事件的发现、报告、处置和恢复流程，确保在账号被盗等事件发生时能够快速响应，最大限度减少损失。

5. **依法合规运营**：依据《网络安全法》《个人信息保护法》《数据安全法》等法律法规，落实账号安全保护义务。

### 1.2 适用范围

本政策适用于以下场景：

1. **账号注册**：用户创建账号时的身份验证和安全设置。

2. **账号登录**：用户每次登录平台时的身份验证流程。

3. **账号找回**：用户忘记密码、邮箱不可用等场景下的账号找回流程。

4. **账号变更**：用户修改密码、更换邮箱、解绑第三方账号等操作。

5. **账号注销**：用户注销账号时的身份验证。

6. **敏感操作**：涉及账户安全、资金、数据删除等敏感操作时的增强验证。

7. **安全事件**：账号被盗、异常登录、密码泄露等安全事件的处置。

8. **第三方绑定**：用户绑定或解绑QQ、微信等第三方账号时的验证。

### 1.3 定义

1. **账号**：指用户在本平台注册的用于登录和使用服务的唯一标识。

2. **身份验证**：指平台通过某种方式确认操作者身份的过程。

3. **单因素验证**：仅通过一种因素（如密码）进行身份验证的方式。

4. **增强验证**：在单因素验证基础上增加额外验证环节（如邮箱验证码）的方式。

5. **账号安全事件**：指账号被他人非法获取、控制、使用或可能导致上述后果的事件。

6. **异常登录**：指与用户惯常登录行为显著不同的登录行为，如异地登录、新设备登录、短时间内频繁登录等。

7. **密码强度**：指密码抵御猜测或暴力破解攻击的能力，通常与密码长度、字符种类、随机性相关。

8. **会话**：指用户登录成功后，平台为其分配的有效访问时段或凭证。

9. **凭证**：指用于证明用户身份的信息，包括密码、验证码、邮箱确认链接等。

10. **社会工程学**：指利用欺骗、诱导等人际手段获取敏感信息或访问权限的攻击方式。

## 第二章 平台的安全措施

### 2.1 密码安全

1. **密码散列存储**：用户密码使用不可逆加密散列算法（如bcrypt、Argon2等）存储，平台任何人员（包括公司负责人）均无法读取明文密码。即使数据库被非法获取，攻击者也无法直接获得明文密码。

2. **密码传输加密**：密码在传输过程中使用TLS加密协议，防止网络拦截。

3. **密码强度建议**：平台在注册时建议用户设置至少8位、包含大小写字母、数字和特殊字符的密码。密码设置过于简单的，平台可提示用户更换但不过度限制。

4. **密码修改**：用户可随时在账户设置中修改密码。修改密码需验证当前密码或通过邮箱验证。

5. **密码找回**：用户忘记密码时，通过注册邮箱验证码重置密码。平台不向任何人提供密码找回服务，不通过邮件索取密码。

### 2.2 会话安全

1. **会话凭证**：用户登录成功后，平台签发会话凭证（令牌）。会话凭证具有时效性，超过有效期后需重新登录。

2. **会话过期**：用户长期未活动的，平台可自动注销会话，要求重新登录。

3. **退出登录**：用户可随时主动退出登录，退出后会话凭证立即失效。

4. **登录状态管理**：用户可查看并管理当前所有活跃会话（如有），并选择性地退出其他设备的登录状态。

### 2.3 登录异常检测

平台对登录行为进行监测，识别以下异常模式：

1. **异地登录**：用户短时间内从地理位置相距较远的地点登录（基于IP地址判断）。

2. **新设备登录**：用户从从未使用过的设备登录。

3. **高频登录尝试**：短时间内大量失败的登录尝试（可能是暴力破解）。

4. **同时多端登录**：同一账号在多个不同地点同时活跃。

5. **异常行为模式**：登录后的行为与用户惯常行为显著不同。

当检测到异常登录时，平台采取以下措施：

1. 要求增强验证（如邮箱验证码）；

2. 通知用户账号存在异常登录；

3. 临时冻结账号（如疑似暴力破解攻击）；

4. 要求用户修改密码。

### 2.4 邮箱验证

本平台使用邮箱作为身份验证的核心方式之一：

1. **注册验证**：注册时通过邮箱验证码确认邮箱归属。

2. **密码找回**：忘记密码时通过邮箱验证码重置密码。

3. **异常验证**：检测到异常登录时，通过邮箱验证码确认操作者身份。

4. **敏感操作验证**：修改密码、更换邮箱、注销账号等敏感操作时，通过邮箱验证码验证。

**邮箱安全的重要性**：由于邮箱是账号找回和异常验证的核心渠道，请确保您的注册邮箱安全。如邮箱被盗，攻击者可能通过邮箱重置密码获取您的平台账号。建议您为邮箱设置独立的高强度密码，并开启邮箱平台提供的双因素认证（如有）。

### 2.5 第三方绑定安全

1. 用户可选择绑定QQ、微信等第三方账号实现便捷登录。

2. 绑定行为发生在第三方平台，平台仅获取用户明确授权的最小必要信息。

3. 用户可随时在账户设置中解除第三方绑定。

4. 第三方账号被盗的，可能导致通过第三方登录的绑定关系被利用。用户应在发现第三方账号安全问题时及时解绑或通知平台。

## 第三章 您的账号安全责任

### 3.1 密码设置与保管

1. **独立密码**：请为您的本平台账号设置与其他平台不同的独立密码，避免因某个平台密码泄露导致多处账号被攻破。

2. **高强度密码**：建议使用至少8位、包含大小写字母、数字和特殊字符的密码。避免使用生日、简单数字序列、常见单词等容易被猜测的密码。

3. **不泄露密码**：不要向任何人（包括平台工作人员、客服）透露密码。平台任何人员均不会向您索要密码。

4. **定期更新密码**：建议定期（如每6-12个月）更换密码，特别是怀疑密码可能泄露时。

5. **密码管理工具**：如您难以记忆多组密码，建议使用专业的密码管理器（如Bitwarden、1Password等）生成和存储密码。

### 3.2 邮箱安全

1. **独立邮箱**：建议为平台账号使用专门或安全的邮箱，并设置独立的强密码。

2. **开启邮箱双因素认证**：如您的邮箱平台支持，请开启双因素认证。

3. **监控邮箱异常**：如收到平台发送的密码重置邮件但您未操作，说明邮箱可能已被他人尝试盗用，请立即采取措施。

### 3.3 设备与网络安全

1. **公共设备**：在公共设备（如网吧电脑、公共图书馆电脑）上登录平台后，请务必退出登录并清除浏览器数据。

2. **不保存密码**：在公共设备上不要勾选“记住密码”或“保持登录状态”。

3. **安全网络环境**：避免在不安全的网络环境（如未加密的公共Wi-Fi）中登录平台进行敏感操作。

4. **设备安全**：请确保您使用的设备安装了可靠的安全软件，避免被植入键盘记录器等恶意程序。

### 3.4 警惕社会工程学攻击

1. **不轻信“官方”主动联系**：平台不会主动通过电话、QQ、微信等方式联系您并要求提供验证码、密码、支付信息。任何此类联系均为诈骗。

2. **不点击可疑链接**：不要点击来源不明的邮件、消息中的链接。平台的通知邮件仅来自官方邮箱 jiangtengqiao@qq.com 及平台公示的其他官方渠道。

3. **不回复可疑邮件**：收到疑似钓鱼邮件（仿冒平台官方，要求您提供账号信息或点击链接）时，请勿回复，直接删除，并可通过官方邮箱向平台举报。

4. **不向他人提供验证码**：验证码仅限您本人使用，不要向任何人透露，包括声称是平台工作人员的人。

### 3.5 及时报告安全事件

如您发现以下情况，请立即通过官方邮箱 jiangtengqiao@qq.com 联系平台：

1. 账号被他人登录；

2. 密码被他人修改；

3. 收到非本人操作的验证码邮件；

4. 注册邮箱可能已被盗；

5. 其他任何您认为账号存在安全风险的异常情况。

## 第四章 身份验证方式

### 4.1 验证方式总览

平台根据操作场景的安全等级，采用以下一种或多种身份验证方式：

| 验证方式 | 说明 | 适用场景 |
| --- | --- | --- |
| 密码验证 | 输入账号密码 | 常规登录 |
| 邮箱验证码 | 向注册邮箱发送一次性验证码，输入验证 | 注册、密码找回、异常登录确认 |
| 密码+邮箱验证码 | 双重验证 | 修改密码、更换邮箱、注销账号 |
| 第三方授权验证 | 通过QQ/微信授权确认 | 第三方绑定登录 |
| 注册信息验证 | 提供注册时间、最近登录信息等 | 异常情况下的补充验证 |
| 身份证明验证 | 提供身份证明文件影印件 | 账号权属存在争议时 |

### 4.2 验证码规则

1. **有效性**：邮箱验证码有效期为10分钟，一次性使用，过期或使用后即失效。

2. **发送频率**：同一账号在短时间内（如10分钟内）最多发送3次验证码，防止恶意刷取。

3. **错误处理**：连续多次输入错误验证码的，平台可暂时锁定验证功能并要求稍后重试。

4. **不索取验证码**：平台不会通过邮件、电话、消息等方式要求您提供验证码。任何索要验证码的行为均为诈骗。

### 4.3 敏感操作的增强验证

以下操作需要增强验证（密码+邮箱验证码或同等验证）：

1. 修改登录密码；

2. 更换注册邮箱；

3. 解除第三方账号绑定；

4. 注销账号；

5. 撤销全部API密钥；

6. 申请数据导出；

7. 其他平台认为需要增强验证的操作。

### 4.4 身份证明验证

在以下场景中，平台可能要求用户提供身份证明文件（如身份证、护照）的影印件：

1. 账号权属存在争议（如多人声称拥有同一账号）；

2. 账号被盗后申请找回但无法通过常规方式验证；

3. 涉及大额交易争议或法律纠纷；

4. 平台合理怀疑存在身份冒用行为。

平台对身份证明文件仅作核实用途，核验完成后 **立即删除**，不保留副本，不用于其他任何目的。用户可在提供身份证明文件时添加水印（如“仅供SEOC Studio账号验证使用”）。

## 第五章 账号安全事件的处置

### 5.1 账号被盗的处置流程

**用户报告账号被盗后，平台按以下流程处置：**

1. **立即响应**：平台收到报告后，立即启动账号安全事件处置。

2. **临时冻结**：立即冻结该账号，防止进一步损失（如研点被消耗、内容被访问）。

3. **身份确认**：通过邮箱验证、身份证明验证等方式确认报告者身份。

4. **调查与恢复**：核实账号异常情况，分析登录日志，确认非法访问时间、来源和操作。

5. **账号恢复**：身份确认后，协助用户重置密码，恢复账号访问。

6. **损失评估**：评估账号被盗期间造成的损失（如研点被消耗、数据被篡改），并根据情况协助恢复或采取补救措施。

7. **安全加固**：建议用户修改密码、检查邮箱安全、解除不必要的第三方绑定。

**处置时限**：平台应在收到账号被盗报告后 **24小时** 内冻结账号，在 **3个工作日** 内完成身份核验和初步处理，在 **7个工作日** 内完成处置和恢复（如可恢复）。

### 5.2 密码泄露事件

如用户怀疑或确认密码已泄露（例如在其他平台使用相同密码且该平台发生数据泄露），应立即：

1. 在本平台修改密码；

2. 检查注册邮箱是否安全；

3. 查看账号是否存在异常登录或操作；

4. 解除不必要的第三方绑定。

平台在获知可能影响用户的第三方数据泄露事件时，将通过邮件等方式提醒用户修改密码。

### 5.3 异常登录通知

平台检测到异常登录时，将通过邮件向用户发送安全提醒。用户收到提醒后，如确认非本人操作，应立即：

1. 通过官方邮箱联系平台冻结账号；

2. 修改密码；

3. 检查邮箱安全；

4. 查看账号操作记录，确认是否有未授权操作。

### 5.4 第三方账号安全事件

用户绑定的QQ或微信账号发生安全事件（如被盗）时，攻击者可能通过第三方授权登录获取平台账号。用户应：

1. 立即在平台解除第三方绑定；

2. 在第三方平台修改密码、申诉找回；

3. 修改本平台密码；

4. 通过官方邮箱通知平台，以便平台加强安全监控。

## 第六章 平台的安全管理

### 6.1 内部访问控制

1. **最小授权**：平台内部对用户账号数据的访问实行最小授权原则。用户密码散列、API密钥等核心凭证仅公司负责人可访问（且仅能通过系统查看散列，无法还原明文）。

2. **操作留痕**：对账号数据的访问、修改、删除等操作均有日志记录，可追溯。

3. **权限审批**：新增访问权限或权限变更需经审批流程。

4. **定期审计**：定期对账号数据访问日志进行审计，发现异常及时处理。

### 6.2 安全监测

1. 平台持续监测针对账号体系的攻击行为，包括暴力破解、撞库、钓鱼等。

2. 对疑似攻击行为，平台采取临时封禁IP、加强验证、锁定目标账号等措施。

3. 发现的大规模攻击行为，平台依法向有关主管部门报告。

### 6.3 安全更新

平台持续关注所依赖的云服务、第三方组件、认证系统的安全公告，及时应用安全更新和补丁。如发现与账号安全相关的漏洞，按照《网络安全漏洞报告与响应政策》处理。

## 第七章 附则

### 7.1 政策的更新
