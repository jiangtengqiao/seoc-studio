# 研点购买与消费协议

最近修订日期：2026 年 8 月 12 日
生效日期：2026 年 8 月 12 日

## 导言

本协议是您与编程研究与探索有限公司（下称"本公司"）之间，就您在 SEOC Studio 研智助手平台购买与消费"研点"虚拟资产所订立的协议。研点是研智助手平台的统一计费单位，用于支付人工智能模型调用产生的 token 费用。请您在充值前仔细阅读本协议。

## 第一条 研点的性质

1.1 研点是平台内部的虚拟计费单位，不具备法定货币属性，不可兑换人民币或其他法定货币，不可向他人转让，不可在不同账户之间流转。

1.2 研点仅可用于研智助手对话与接口调用，不可用于购买本平台其他数字内容（订阅式、专研式、探索式项目），亦不可折抵其他产品价款。

1.3 研点不记名、不挂失、不生息。账户注销后，账户内未消耗的研点随之清零，不予折现或转移。

## 第二条 充值方案与价格

2.1 平台提供多档充值方案，具体档位、单价与赠送规则以研点管理页面实时公示为准。本公司有权根据第三方模型市场价格、汇率波动与运营成本实时调整充值方案，已充值到账的研点不受后续调价影响。

2.2 充值按"人民币付款、研点到账"的方式完成。您可通过平台公示的支付宝或微信收款码支付，并在付款备注中填写注册邮箱以便核验。

2.3 充值采用人工确认制，与[数字内容购买协议](purchase-agreement)一致的流程。您提交充值订单后订单状态为"待确认"，本公司核验到账后将订单标记为"已确认"，系统自动将对应研点记入您的账户并记入交易流水。

2.4 研点到账以订单状态变更为"已确认"为准。一般情况下核验在一个工作日内完成，如长时间未到账请将付款凭证发送至 jiangtengqiao@qq.com。

## 第三条 计费规则

3.1 每次调用按所选模型的输入单价（每千输入 token 研点数）与输出单价（每千输出 token 研点数）分别计算，公式为：消耗研点 = 输入 token / 1000 × 输入单价 + 输出 token / 1000 × 输出单价，精确到小数点后四位。

3.2 各模型的实时单价在研智助手模型选择框、研点管理页与 API 文档中公示。当模型由第三方厂商调价时，本公司将同步调整并公示，调整对已发起但未完成的调用不溯及。

3.3 部分模型提供每日免费额度。免费额度优先于研点余额消耗，按模型独立计算，每日零点（北京时间）重置，未用完部分不予累积。

3.4 当输出过程中累计消耗超过余额时，平台将强制中断输出并提示"研点不足"。中断时已生成的 token 已实际消耗，照常计费且不予退还。

## 第四条 退款政策

4.1 研点为虚拟资产，一经充值并经核验到账即视为服务已开始提供，原则上不予退款。

4.2 下列情形本公司可酌情处理：因平台系统故障导致研点异常扣减的，经核实后补回；因法律法规导致服务完全终止且无法继续提供的，未消耗研点按充值比例折算退还。

4.3 因您自身原因（误充值、不再使用、违反协议被封禁等）要求退款的，本公司有权拒绝。详见[退款政策](refund-policy)。

## 第五条 禁止行为

5.1 您不得通过任何技术手段篡改余额、伪造交易、绕过计费或刷取免费额度。

5.2 您不得利用多个账户批量领取免费额度再整合使用，一经发现本公司有权合并清零相关账户的免费额度并冻结违规账户。

5.3 您不得将研点或 API 调用额度以任何形式转售、共享或变现给非账户持有人。

## 第六条 异议与联系

如对充值金额、扣费明细或到账状态有异议，请在订单生成之日起三十日内通过 jiangtengqiao@qq.com 提出，逾期视为认可。本公司将在收到异议后五个工作日内核查并回复。
