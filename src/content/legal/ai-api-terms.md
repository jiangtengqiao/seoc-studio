# API 开放平台服务条款

最近修订日期：2026 年 8 月 12 日
生效日期：2026 年 8 月 12 日

## 导言

本条款适用于您通过 SEOC Studio 研智助手开放平台提供的 API 接口（OpenAI 兼容格式）调用人工智能模型的服务。您在创建或使用 API 密钥前应仔细阅读本条款。本条款是[研智助手 AI 服务协议](ai-service-agreement)的补充，与该协议不一致处，在 API 调用范围内以本条款为准。

## 第一条 接口与兼容性

1.1 本平台提供 OpenAI 兼容的 Chat Completions 接口，端点与认证方式以 API 密钥管理页"接口文档"栏目公示为准。您可使用官方 OpenAI SDK 或任何兼容客户端接入。

1.2 接口支持流式与非流式两种模式，支持多模型切换。可用模型列表、模型 ID 与实时单价以接口文档与模型管理公示为准。

1.3 本平台对接口的可用性不做绝对保证，接口可能因第三方厂商状态、平台维护或流量控制出现限流、延迟或临时不可用。本公司会尽合理努力保障稳定，但不承诺特定的可用率。

## 第二条 认证与密钥

2.1 您可在 API 密钥管理页创建多个密钥并自定义名称。密钥采用 `sk-seoc-` 前缀格式，仅在创建时完整显示一次，请妥善保存。密钥以 SHA-256 哈希形式存储，本平台无法逆向还原明文。

2.2 每次调用使用 Bearer Token 认证，密钥校验通过后关联至您的账户进行计费。API 调用不享受免费额度，全部从您的研点余额扣费。

2.3 密钥泄露或不再使用时，请立即在管理页撤销。因密钥泄露导致的消耗由您自行承担，本公司不负责追回。

## 第三条 计费与额度

3.1 API 调用计费规则与网页端一致，按输入与输出 token 分别计价，精确到小数点后四位，详见[研点购买与消费协议](ai-credits-policy)。

3.2 调用前平台会校验研点余额，余额不足时返回 402 状态与 `insufficient_quota` 错误。调用过程中余额耗尽时，流式输出将被中断并返回 `finish_reason: length`，中断时已生成部分照常计费。

3.3 平台有权根据负载情况对单账户的并发数与每分钟调用次数设置合理上限，超出时返回 429 状态。

## 第四条 使用规范

4.1 您应遵守[研智助手 AI 服务协议](ai-service-agreement)第四条的使用规范，不得通过 API 生成违法或侵权内容，不得实施越狱攻击或恶意指令注入。

4.2 您不得将接口以盈利为目的转售或公开共享给非账户持有人使用，不得将单一密钥分发给多个终端用户作为公开服务。如需构建面向第三方的产品，应事先与本公司协商获取相应授权。

4.3 您不得对接口进行压力测试、暴力枚举或任何可能影响平台与其他用户正常使用的请求。发现异常调用，本公司有权限流或封禁密钥。

4.4 您应遵守接口所属模型厂商的使用条款，详见[第三方 AI 模型使用说明](ai-third-party-models)。因您违反厂商条款导致厂商向本公司追责的，本公司有权向您追偿。

## 第五条 变更与终止

5.1 本公司有权根据厂商政策与运营需要调整接口规格、模型列表与计费标准，调整在平台公示后生效。

5.2 您可随时停止使用并撤销全部密钥。本公司可在您严重违反本条款时终止您的 API 调用权限，已充值研点按[退款政策](refund-policy)处理。

## 第六条 免责

接口输出由人工智能模型生成，存在[AI 生成内容免责声明](ai-content-disclaimer)所述的一切风险。本公司对接口中断、输出错误、数据丢失等情形的责任以您实际消耗研点对应金额为限。
