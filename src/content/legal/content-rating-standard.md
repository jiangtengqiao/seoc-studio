# 新增主协议二：内容分级与敏感信息标注规范

**最近修订日期：2026年8月14日  生效日期：2026年8月14日**

## 欢迎语与适用范围

欢迎您使用 SEOC Studio（编程研究与探索）平台。本平台由编程研究与探索有限公司（下称“我们”或“本公司”）开发并运营。为了维护健康、有序的内容生态，保障不同年龄阶段、不同需求和偏好的用户群体能够安全、舒适地访问内容，我们建立了内容分级与敏感信息标注体系。

本《内容分级与敏感信息标注规范》（以下简称“本规范”）旨在向您清晰说明：本平台对内容进行分类分级的依据和标准、各类内容标签的含义、敏感信息的识别与标注方式、不同等级内容的展示与访问规则、用户设置内容偏好的方法，以及内容分级争议的处理机制。

本规范适用于本平台内所有可展示的内容，包括但不限于：平台官方发布的内容（数字内容、公告、文档等）、用户生成内容（UGC，包括讨论区帖子、评论、代码分享、教程等）、AI生成内容、附赠资料、讨论区互动内容等。

本规范与《用户生成内容政策》《AI生成内容分级标注实施细则》《可接受使用政策》《隐私政策》等文本共同构成完整约定。涉及AI生成内容的分级标注，本规范与《AI生成内容分级标注实施细则》具有特殊与一般的关系，AI生成内容优先适用细则。

**特别提示**：内容分级与标注是我们为保护用户而采取的自律措施，不替代法律法规对违法内容的管理。含有违法信息的内容无论其分级为何，一律禁止发布和展示。

## 第一章 总则

### 1.1 制定目的

本规范的制定旨在实现以下目的：

1. **内容分类管理**：对平台内各类内容进行合理分类，便于用户快速检索和识别。

2. **年龄适宜性分级**：按内容的知识深度、技术复杂性和敏感性进行分级，帮助用户尤其是未成年人的监护人判断内容是否适合阅读。

3. **敏感信息标注**：对内容中可能涉及的个人隐私、安全漏洞、恶意代码、争议话题等敏感信息进行标注，提醒用户注意。

4. **用户自主选择**：通过标签和过滤设置，让用户根据自身需求和偏好选择浏览内容。

5. **合规运营**：依据《网络信息内容生态治理规定》《未成年人保护法》等法规要求，履行平台内容管理义务。

6. **AI内容标识**：根据《互联网信息服务深度合成管理规定》等法规，对AI生成内容进行显式标识，防止误导。

### 1.2 适用范围

本规范适用于平台内以下内容类型：

1. **平台官方数字内容**：研究报告、教程、文档、专题文章等。

2. **用户生成内容（UGC）**：讨论区帖子、评论、问答、代码分享、个人简介、作品展示等。

3. **AI生成内容**：通过本平台AI服务生成或辅助生成的内容。

4. **附赠资料**：随数字内容附赠的额外资料。

5. **其他内容**：平台公告、系统通知、邮件内容等（如涉及分级标注需要）。

### 1.3 定义

本规范中下列术语的含义为：

1. **内容分级**：指根据内容的年龄适宜性、技术深度、敏感性等因素，将内容划分为不同的等级并标注相应标签。

2. **敏感信息标注**：指对内容中可能涉及个人隐私、安全风险、争议话题等的信息添加警示标签或说明。

3. **AI生成内容标识**：指对由AI生成或以AI为主要辅助生成的内容添加“AI生成”等标识，使用户知悉内容的真实来源。

4. **标签**：指附着在内容上的简短说明文字或图标，用于描述内容的属性、分级或警示。

5. **内容过滤**：指用户通过设置偏好，自动过滤或隐藏特定分级或标签内容的功能。

6. **年龄适宜性**：指内容对特定年龄阶段用户的适合程度。

### 1.4 基本原则

1. **合法合规原则**：内容分级不改变法律对违法内容的禁止性规定。违法内容不因分级而获得合法性。

2. **保护未成年人原则**：通过分级和过滤机制，尽力防止未成年人接触不适宜的内容。

3. **透明标注原则**：内容分级和标注应公开、透明、可理解，用户在阅读前可清晰了解内容属性。

4. **最小标签原则**：仅对需要标注的内容添加标签，不对正常内容施加不必要的限制。

5. **用户自主原则**：用户可根据自身判断和需求设置内容偏好和过滤规则。

6. **动态调整原则**：内容分级标准和标签体系可根据法规变化、社区反馈和平台运营需要动态调整。

## 第二章 内容分级体系

### 2.1 年龄适宜性分级

本平台将内容按年龄适宜性分为以下等级：

| 等级 | 标签 | 适用年龄 | 说明 |

| --- | --- | --- | --- |

| G | 全龄适合 | 所有年龄 | 内容安全、无害，无任何敏感主题，适合包括未成年人在内的所有用户。 |

| T | 青少年适合 | 12岁以上建议 | 内容可能包含较深入的技术知识、轻微的代码风险提示（如教程中演示的测试代码），但无不当内容。 |

| A | 成人内容 | 18岁以上 | 内容可能包含深度安全研究、漏洞分析、攻击防御技术、代码安全测试、较复杂的技术讨论等，可能不适合未成年人和初学者。 |

**说明**：本平台核心内容以编程技术为主，无娱乐性内容。成年级内容主要针对安全研究、漏洞分析、恶意代码防御等专业领域，不包含法律禁止的色情、暴力等内容。

### 2.2 技术深度分级

为帮助用户识别内容的技术难度，平台另设以下技术深度标签：

| 等级 | 标签 | 说明 |

| --- | --- | --- |

| 入门 | 入门/基础 | 面向零基础或初学者，内容浅显易懂 |

| 中级 | 中级/进阶 | 面向有基础的开发者，包含较复杂概念 |

| 高级 | 高级/专业 | 面向经验丰富的开发者或安全研究者，内容深入、专业性极强 |

### 2.3 分级标准

内容分级的判定依据包括：

1. **安全敏感性**：是否涉及安全漏洞、攻击工具、恶意代码分析、防御绕过等安全敏感内容。

2. **技术复杂性**：内容涉及的编程语言难度、概念深度、前置知识要求。

3. **数据风险**：内容是否涉及个人隐私数据获取、处理、传输的详细操作。

4. **法律风险**：内容是否涉及可能被滥用于违法的技术细节。

5. **争议话题**：内容是否涉及可能引发争议或对立的话题。

### 2.4 分级变更

1. 平台有权根据内容审核结果、用户反馈或法规变化，对已发布内容的分级标签进行变更。

2. 分级变更后，平台通过站内信或邮件通知内容作者。

3. 用户可对分级提出异议，按第六章程序处理。

## 第三章 敏感信息标注

### 3.1 标注类型

平台对以下类型的敏感内容添加标注：

1. **安全风险标注**：内容涉及安全漏洞披露、攻击技术演示、恶意代码分析等，标注“安全研究”或“可能被滥用”标签。

2. **个人隐私标注**：内容涉及大量个人信息的处理、可能包含他人隐私信息的，标注“含个人信息”标签。

3. **代码安全标注**：内容中的代码可能含有安全风险、运行后可能导致系统问题，标注“代码安全警示”。

4. **AI生成标注**：内容全部或主要部分由AI生成，标注“AI生成内容”。

5. **争议话题标注**：内容可能引发技术争议、观点分歧的，标注“可能存在争议”。

6. **时效性标注**：内容涉及快速过时的技术信息，标注“可能过时”。

### 3.2 标注方式

1. **标签显示**：在内容标题旁或正文开头显示标签图标和文字。

2. **前置警示**：对高风险内容，在用户点击进入前弹出警示提示，要求用户确认后访问。

3. **正文内标注**：在内容的敏感段落旁添加标注，提醒用户注意。

4. **发布时提示**：用户发布内容时，系统根据内容自动识别或要求用户手动添加相应标签。

### 3.3 用户发布内容的自评义务

用户发布UGC时，有义务对内容的敏感属性进行自评并选择相应的分级和标签。具体要求：

1. 发布涉及安全漏洞、攻击技术的，应选择“A级+安全风险标注”；

2. 发布可能包含他人隐私信息的，应添加“含个人信息”标注；

3. 发布AI生成内容或主要借助AI完成的内容，应添加“AI生成内容”标注；

4. 用户不确定如何分级的，可选择“A级”并注明“分级可能不准确”，由平台审核调整；

5. 故意隐瞒敏感属性、不标注的，按《用户生成内容政策》违规处理。

### 3.4 AI生成内容的强制标识

根据《互联网信息服务深度合成管理规定》等法规，本平台对AI生成内容实行强制标识：

1. **显式标识**：AI生成的内容在正文开头或结尾显著位置标注“本内容由AI生成”或“本内容含AI生成部分”。

2. **用户提示**：用户通过平台AI服务生成内容时，系统默认添加AI生成标签，用户不得删除。

3. **不可去除**：AI生成标识为强制性标识，不可通过修改代码、工具等方式去除。

4. **细化标识**：对于部分由AI生成、部分由人工撰写的内容，应明确标注AI生成部分的范围。详见《AI生成内容分级标注实施细则》。

### 3.5 平台审核

平台对已发布内容的标注进行审核：

1. **自动化检测**：通过文本分析、模式识别等技术检测可能被遗漏标注的敏感内容。

2. **人工抽检**：定期对已标注内容进行抽检，核实标注准确性。

3. **用户举报**：用户可举报标注不准确的内容，平台核实后调整标注。

## 第四章 展示与访问规则

### 4.1 默认展示规则

1. 所有用户默认可见G级和T级内容。

2. A级内容默认对未登录用户和未成年人隐藏，登录的成年用户可正常浏览。

3. 带有“安全风险标注”“含个人信息标注”的内容，在首次访问时弹出提醒提示，用户确认后进入。

### 4.2 用户自定义过滤

用户在账户设置中可配置内容过滤偏好：

1. **年龄适宜性过滤**：选择隐藏A级内容（默认未成年人隐藏）。

2. **敏感标签过滤**：选择隐藏带特定标签的内容（如“安全研究”“争议话题”等）。

3. **AI内容偏好**：选择是否在推荐或浏览中显示AI生成内容。

4. **过滤生效范围**：过滤设置适用于讨论区、搜索、推荐等场景。付费数字内容不受过滤影响，但购买前会展示相应标签。

### 4.3 对未成年人的特别保护

1. 本平台谢绝未成年人独立注册。但未成年人可能以访客身份浏览公开内容。

2. 未登录访客默认仅可浏览G级和T级内容，A级内容不展示。

3. 对含有安全研究、漏洞利用、恶意代码分析等标签的A级内容，平台限制展示在公开列表，需主动搜索或直接访问链接才能看到（且仍需登录成年账号）。

4. 平台不向未成年人推荐A级内容，不通过邮件、站内信等方式向未成年人账号发送A级内容推送。

### 4.4 内容作者的义务

1. 发布内容时，作者应如实选择内容分级和添加敏感标注。

2. 内容升级或增加敏感话题时，作者应及时更新标注。

3. 作者隐瞒分级或故意错误标注的，平台可强制调整标注，并按违规处理。

4. 作者对AI生成内容不得故意去除或规避AI标识。

## 第五章 与AI生成内容相关的特别规定

### 5.1 AI生成内容的范围

本规范所称AI生成内容包括：

1. 用户使用本平台AI服务（如研智助手）生成的文本、代码、分析结果等；

2. 用户在第三方AI平台生成后搬运到本平台的内容；

3. 人类与AI协作创作、AI参与度较高的内容；

4. 本平台使用AI自动生成的内容（如AI摘要、AI翻译、AI分类标签等）。

### 5.2 AI生成内容的标注要求

1. 用户使用本平台AI服务生成内容并发布到讨论区等公开场景的，系统自动添加“AI生成内容”标签。

2. 用户从外部AI工具生成并搬运到平台的，用户在发布时应手动勾选“含AI生成内容”标签。

3. AI生成内容如涉及安全研究、漏洞分析等敏感领域的，还需叠加“安全风险标注”。

4. AI生成的内容不得冒充完全人工原创。对于以AI内容冒充原创并参与原创激励活动的，按违规处理，追回激励。

### 5.3 AI生成内容的质量与真实提示

1. AI生成内容可能存在事实错误、过时信息、虚构内容等风险，平台在AI输出中展示“AI生成内容可能不准确，请核实”等提示。

2. 用户引用或依赖AI生成内容进行重要决策前，应自主核实。

3. 平台对AI生成内容的准确性不做保证，具体免责见《AI生成内容免责声明》。

### 5.4 细则

AI生成内容的分级标注、标识样式、用户义务等具体执行细则，参见《AI生成内容分级标注实施细则》。

## 第六章 分级争议与申诉

### 6.1 用户对分级的异议

用户如认为某内容的标注不准确、分级过高或过低，可通过以下渠道提出：

1. 在内容页面点击“举报”并选择“标注错误”；

2. 通过官方邮箱 jiangtengqiao@qq.com 提交申诉。

### 6.2 处理流程

1. 平台在收到申诉后 **3个工作日** 内登记并初步审查。

2. 需调整标注的，平台在 **5个工作日** 内完成调整并通知申诉人。

3. 维持原标注的，向申诉人说明理由。

4. 申诉人对处理结果不服的，可依《投诉处理与争议解决政策》投诉。

### 6.3 作者对标注调整的异议

内容作者对平台调整其内容标注有异议的，可依《投诉处理与争议解决政策》提出申诉。
